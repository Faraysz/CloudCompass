# 🌦️ Tracking API - Real-Time Weather App

**Tracking API** adalah aplikasi lintas platform (cross-platform) yang dibangun menggunakan **Flutter** untuk melacak dan menampilkan informasi cuaca secara real-time berdasarkan lokasi pengguna. Aplikasi ini mengintegrasikan **OpenWeather API** untuk menyediakan data cuaca yang akurat dan terkini.

---

## ✨ Fitur Utama
- 🌍 **Location-Based Tracking**: Mendapatkan data cuaca otomatis berdasarkan lokasi GPS pengguna.
- 🌦️ **Real-Time Weather**: Menampilkan informasi cuaca terkini (suhu, kelembapan, kondisi cuaca, kecepatan angin, dll).
- 📱 **Cross-Platform**: Berjalan lancar di berbagai platform:
  - Android
  - iOS
  - Web
  - Desktop (Windows, macOS, Linux)
- 🎨 **Responsive UI**: Tampilan yang adaptif untuk berbagai ukuran layar.
- 🔄 **API Integration**: Terintegrasi penuh dengan OpenWeather API menggunakan package `http`.

---

## 🛠️ Tech Stack

| Teknologi | Keterangan |
|-----------|------------|
| **Framework** | Flutter (Dart SDK ^3.7.2) |
| **Networking** | `http` package (^1.4.0) |
| **API** | [OpenWeather API](https://openweathermap.org/api) |
| **UI Components** | Material Design & Cupertino Icons |
| **Platforms** | Android, iOS, Web, Windows, macOS, Linux |

---

## ⚙️ Persyaratan Sistem
Pastikan Anda telah menginstall:
